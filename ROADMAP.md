# Дорожная карта проекта: Panama Runner

## ПРАВИЛА ДЛЯ ИИ-АССИСТЕНТА
1. Выполняем СТРОГО по одному пункту за раз (одна галочка = один промпт).
2. Не переходим к следующему шагу без явной команды "Работает, идем дальше".
3. Код пишем частями. Если нужно изменить существующий метод, выводим ТОЛЬКО его, а не весь класс.
4. НИКАКОГО рефакторинга работающего кода без прямого приказа.

---

## Фаза 1: Базовая настройка и Архитектура (Domain)
- [х] 1.1. Настроить `build.gradle` (добавить Compose, Coroutines, ViewModel, Firebase, Yandex Mobile Ads, ARCore).
- [х] 1.2. Создать структуру пакетов: `domain`, `presentation`, `data`, `di`.
- [х] 1.3. В `domain/models` создать `sealed class GameObject` (Panama, BadPanama). Задать параметры: x, y, радиус/размер, скорость падения.
- [х] 1.4. Создать `data class GameState` (очки прогресса `score` до 1000, счетчик брака `missedCount` до 12, список объектов, статус: PLAYING, GAME_OVER, PAUSED, WON).
- [x] 1.5. В `domain/usecases` создать `GameEngine` для игрового тика. Реализовать динамическую сложность: скорость падения объектов и шанс появления `BadPanama` должны расти в зависимости от текущего `score` (чем ближе к 1000, тем сложнее).
