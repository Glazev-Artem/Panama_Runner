## 4.

Правила Чистой Архитектуры (Изоляция слоев)

-

**Data-слой:** DTO, Room Entities и модели сетевых ответов (Retrofit/Ktor) НЕ

ДОЛЖНЫ покидать слой Data.

- **Domain-слой:** Содержит только чистую бизнес-логику (UseCases,

Domain Models, Repository Interfaces). Никаких зависимостей от Android SDK (Context, View) или

конкретных баз данных в этом слое быть не должно. Обязательно используй мапперы

для преобразования данных из Data в Domain.

-

**Presentation-слой:** UI (Compose/XML) ничего не знает о базах данных или
сети. Общение идет только через ViewModel, которая дергает UseCases. Используй
UDF (Unidirectional Data Flow) / MVI.



## 5.

КОНТЕКСТ ПРОЕКТА "PANAMA RUNNER"
- **Стек:** Kotlin, Jetpack Compose, Coroutines, Canvas (для 2D), Firebase (Auth, Firestore), Yandex Mobile Ads, ARCore (для примерки панамы).

- **Победа:** При счете 1000 — экран с промокодом и ссылкой на Wildberries.
- **Сохранение:** Прогресс сохраняется в Firebase при сворачивании игры.
